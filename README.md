# Generative AI & Agentic AI Learning Journey

Welcome to my learning journey into **Python, Generative AI, and Agentic AI**.

This repository documents my progress as I explore AI engineering concepts, experiment with Large Language Models (LLMs), and build practical AI-powered applications.

My goal is to develop a strong understanding of AI technologies and learn how to design and build intelligent applications through hands-on projects.

## 🎯 Learning Objectives

- Learn Python from fundamentals to the level required for AI development.
- Understand Generative AI, Large Language Models (LLMs), and their underlying concepts.
- Integrate LLM APIs into Python applications.
- Learn prompt engineering and structured outputs.
- Understand tokenization, embeddings, and vector databases.
- Build applications using Retrieval-Augmented Generation (RAG).
- Learn AI agents, tool calling, and agent workflows.
- Explore Model Context Protocol (MCP) and multi-agent systems.
- Build practical AI-powered automation applications.

## 🛠️ Technology Stack

Technologies and tools currently being explored:

- **Programming Language:** Python
- **LLM Provider:** Google Gemini
- **Libraries:** Google GenAI SDK, python-dotenv
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub

This technology stack will evolve as I explore additional tools and frameworks.
